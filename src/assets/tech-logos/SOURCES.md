# Technology mark sources

The showcase embeds the SVG artwork without recoloring it. Neutral backings under dark marks improve contrast.

- Devicon 2.17.0 supplies the original SVG variants for React, Next.js, TypeScript, JavaScript, HTML5, CSS3, Tailwind CSS, Three.js, Vite, Node.js, Express.js, Python, FastAPI, Firebase, MongoDB, PostgreSQL, Supabase, Git, GitHub, GitHub Actions, Docker, Vercel, Postman and VS Code. [Devicon source](https://github.com/devicons/devicon/tree/v2.17.0/icons)
- GSAP uses the green wordmark from its brand page. [GSAP brand assets](https://gsap.com/brand/)
- Groq uses the orange site mark from its own site. [Groq mark](https://groq.com/favicon.svg)
- Gemini API uses the multicolor Gemini spark from LobeHub Icons 1.102.0. [Bundled SVG source](https://cdn.jsdelivr.net/npm/@lobehub/icons-static-svg@1.102.0/icons/gemini-color.svg)
